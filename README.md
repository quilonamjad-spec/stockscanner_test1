# Stretch Monitor (Streamlit + yfinance)
Quick-look version for when you are away from the main setup. Data is from Yahoo Finance (delayed).

Local: `pip install -r requirements.txt` then `streamlit run streamlit_app.py`

GitHub + Streamlit Community Cloud:
1. Put `streamlit_app.py` and `requirements.txt` in a GitHub repo (no `.env`, no Angel One keys; none are needed here).
2. share.streamlit.io -> New app -> pick the repo -> main file `streamlit_app.py` -> Deploy.
Use NSE symbols without suffix (RELIANCE, TCS). Not investment advice.
